# 记忆

## 这是什么

记忆让 Agent 跨对话了解你和你的项目：偏好、人物、决策和过去的工作都可以被找回。它与[助理](assistant)可编辑的资料记忆、每日笔记是分开的。

此功能只在包含记忆的构建中提供。如果没有 **Settings > Memory**，说明该构建未启用这套记忆库。

## 工作原理

每个主题有一页当前摘要，以及解释理解为何变化的时间线。Agent 可以检索旧上下文、保存新事实，不必每提一次就建一页。

Operon 提供两个工具：

- **`memory_search`** — 用关键词和语义相似度查找相关页面与近期时间线。
- **`memory_upsert`** — 保存事实并说明原因。已有相似页面时，Agent 必须先决定合并还是另建。

### 合并

相关事实会在合适时合并到已有主题。当前摘要按新的事实重写，时间线则保留变化历史。发现结果过时时，可以直接告诉 Agent 什么变了。

### 用户记忆

关于你的事实和偏好都归入唯一的 **User** 页面。项目、人物、服务等具名事物各有自己的页面。

### 存储

页面和搜索索引保存在桌面端本地，向量也在本机生成。检索出的信息会成为当前 Agent 的上下文，因此会沿所选模型提供商的数据路径处理。

## 记忆分类

- **User** — 你的角色、背景、偏好和工作方式。
- **Entities** — 人物、项目、服务及其他具名事物。
- **Events** — 有日期的事件、决策和里程碑。
- **Cases** — 调查、解决过程和可复用的工作流程。

## 管理记忆

### 浏览

1. 打开 **Settings > Memory**。
2. 切到 **Memory** 子页签，查看每页的分类与当前摘要，展开后阅读时间线。
3. 用搜索查找相关上下文，或按分类筛选。

### 删除

删除页面会同时移除摘要、时间线和搜索向量。以后对话再次提起时，仍可能重新保存该主题。

## 记忆维护

在 **Settings > Memory > Maintenance** 选择 Agent、模型和每日运行时间，从近期对话提取漏记的信息。也可以手动运行、限制扫描的对话数量，并查看近期运行记录与日志。

## 向量模型配置

语义搜索需要本地向量模型。

1. 打开 **Settings > Memory**，选择 **Embedding**。
2. 下载 **Qwen3-Embedding-0.6B**。
3. 检查可用加速方式，下载完成后测试模型。也支持 CPU 回退。

关键词与语义搜索互为补充；向量模型不会替代你为对话选择的模型。
