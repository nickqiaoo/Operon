# 浏览器

## 这是什么

Operon 内置了一个网页浏览器作为面板标签，让你能在聊天旁边直接预览正在运行的应用，无需离开窗口。在普通浏览之上，它还加入了**页面注释**：切到注释模式，点击页面上的元素、写下批注，再把这些批注作为可操作的上下文直接发给 Agent——非常适合在自己的开发服务器上做"修一下这个按钮"/"收紧这里的间距"这类反馈。

这个浏览器同样可以由 Agent 驱动。打开 **Browser Use** 后，Agent 能自己打开页面、点击、输入、读取所见内容——于是它可以对着运行中的应用检验自己的成果，而不是靠猜。详见下面的 [Agent 自动化](#agent-自动化)。

## 打开浏览器

在右侧或底部面板打开一个 **Browser** 标签（与 Files、Review、Terminal 共用同一套面板系统）。每个工作区会记住自己打开的标签。

当一个新的浏览器标签还没有 URL 时，它不会显示空白页，而是显示一个**本地服务器**落地页——列出你最近访问过的 localhost 端口，让你一键回到 `localhost:3000` 之类的开发服务器。

## 导航

地址栏支持智能输入：

- 完整 URL（`https://…`）原样加载。
- 含空格的文本会变成 Google 搜索。
- 裸域名会自动补上 `https://`。

后退 / 前进 / 刷新（加载中会变成停止按钮）、把页面截图复制到剪贴板的截图按钮，以及一个三点菜单，共同构成了导航条。菜单里还提供强制刷新、设备工具栏开关、缩放控制，以及清除 Cookie 或缓存。

## 设备模拟

打开**设备工具栏**可把页面约束到固定的手机或平板视口，无需缩放窗口即可检查响应式布局。

## 页面注释

这是为"与 Agent 协作"而打造的部分。

1. 在地址栏打开**注释模式**。
2. 点击页面上任意元素。Operon 会放下一个 pin、捕获该元素并测量它的样式。
3. 在弹出的编辑器里为该元素写下批注。
4. 想标多少元素就标多少，每个都有自己的 pin。

标注完成后，地址栏会出现一个 **Send N** 按钮。发送会把你所有的注释作为结构化上下文交给聊天，Agent 便能确切知道你指的是哪些元素、想改什么。一个 **before/after** 开关可让你预览设计改动，垃圾桶按钮可清空当前标签的注释。

注释也会出现在聊天侧的一个托盘里，方便你在发送前查看和管理。

## Agent 自动化

注释是**你**指向页面的方式；Browser Use 则是 **Agent** 自己操作页面的方式。

在 **Settings > Browser Use** 打开它。这会为你的 Agent 安装 Browser 技能；关闭则移除该技能，Agent 将完全看不到浏览器。

打开后，Agent 可以：

- 打开并导航页面，包括你的 `localhost` 开发服务器；
- 读取页面结构来定位元素，而不是靠猜坐标；
- 点击、输入、填写表单、上传文件；
- 在需要看结果时截图。

这个浏览器适用于**不需要**你身份的工作——验证本地应用、读取公开页面、一次性导航。它有自己独立的配置文件，接触不到你真实浏览器的会话。当任务确实需要你的登录态和 Cookie 时，Agent 会改用 [Chrome 集成](chrome)。

### 站点审批

Agent 首次打开某个站点前会询问。你可以只对当次会话放行，也可以对所有会话放行。

**Settings > Browser Use** 会列出那些被保留下来的授权：

- **Approved sites** — 在所有会话中都放行的站点。撤销之后，Agent 下次再去就得重新询问。
- **来自过往会话的授权** — 只显示一个数量，配一个"全部清除"按钮。单条的会话级授权不会逐条列出，因为它们随会话一起消失。

授权在你关闭再打开 Browser Use 之后依然有效；它们存储在磁盘的 `~/.operon/browser/`。

### Full CDP access

默认关闭。它允许 Agent 发送原始的 Chrome DevTools Protocol 命令，而不只是高层的浏览器动作。这个能力很强、难以审计，而且很少用得上——除非确有需要，否则保持关闭。
