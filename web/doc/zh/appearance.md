# 外观

**Settings > Appearance** 负责 Operon 长什么样、说什么语言。

## 语言

可以选择 **English**、**简体中文**，或用 **System** 跟随系统或浏览器语言。切换立即生效，无需重启。

这项设置选择界面语言，助理也会将它作为默认回复语言。工作区 Agent 的回复语言请在消息或指令中指定。

## 主题

**Light**、**Dark** 或 **System**——System 跟随 macOS 一起切换。

## 配色预设

亮色和暗色各有自己的预设，因此你可以把 GitHub Light 和 Tokyo Night 搭在一起，让两种模式各自成立。

| 暗色预设 | 亮色预设 |
| --- | --- |
| Default、One Dark、Nord、Dracula、Tokyo Night、Catppuccin、Gruvbox、Solarized、Rose Pine | Default、One Light、Nord Light、GitHub、Tokyo Night Day、Dracula Light、Catppuccin Latte、Gruvbox Light、Solarized、Rose Pine Dawn |

## 终端主题

内置[终端](terminal)有自己独立的亮色与暗色预设，与 UI 主题分开设置。终端配色方案自带一套约定——而且在 shell 里好看的配色，很少是你想放在聊天背后的那一套——所以两者刻意没有联动。
