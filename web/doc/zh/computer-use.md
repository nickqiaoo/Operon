# Computer Use

## 这是什么

Computer Use 让 Agent 操作**原生 Mac 应用**——读取屏幕上的内容，然后在其中点击、输入、滚动、按键。它面向那些没有 API、没有 CLI、也没有 MCP 服务器的工作：桌面邮件客户端、设计工具、老旧的内部系统、系统设置面板。

点击会直接投递到目标窗口，因此 Agent 可以操作位于后台的应用，而你继续在另一个窗口里工作。

它运行在连接的 Mac 上。请在桌面端启用并授予 macOS 权限；远程客户端没有这个本地设置页。

## 开启

1. 进入 **Settings > Computer**。
2. 打开开关。

打开后会为你的 Agent 安装 Computer Use 技能并启动原生引擎；关闭则移除该技能并停止引擎——此后 Agent 无法看到或操作你的应用。

## 系统权限

macOS 把这些权限授予**原生引擎**，而不是 Operon 主窗口。设置页会实时显示两项权限的状态，并提供一个直接跳到系统设置对应面板的按钮。

| 权限 | 用途 |
| --- | --- |
| **辅助功能（Accessibility）** | 读取应用界面，发送点击与按键 |
| **屏幕与系统录音（Screen & System Audio Recording）** | 应用截图与实时预览窗口 |

没有屏幕录制权限就没有预览、也没有截图——但辅助功能仍然可用，所以 Agent 会表现为"在盲操作"，而不是直接报错。

> 重新构建、移动或替换 App 都可能静默吊销已授予的权限。如果 Computer Use 突然看不到某个应用，先回到这个页面检查，再去排查别的原因。

## Agent 如何"看见"应用

Agent 默认不靠像素工作，而是读取应用的**辅助功能树（accessibility tree）**——一份描述所有窗口、控件与标签的文本，其中每个元素都带有索引。

- 动作通过元素索引定位，而不是坐标，这比点击某个位置可靠得多。
- 每次动作之后 Agent 会重新读取状态，因为索引每次都需要重新推导。
- 再次读取时只返回**变化的部分**——新增了什么、少了什么、改了什么——所以聊得再久开销也不高。
- 截图是兜底手段，用于辅助功能树不完整的场景，例如大量使用 canvas 或自绘 UI 的应用。

应用可以用显示名（`Google Chrome`）、完整路径或 bundle identifier（`com.google.Chrome`）指定。如果应用没有运行，读取其状态会在后台自动启动它。

## Agent 能做哪些动作

| 动作 | 说明 |
| --- | --- |
| `click` | 点击元素或坐标；支持右键、中键与双击 |
| `type_text` / `set_value` | 向焦点元素输入文本，或直接设置某个字段的值 |
| `press_key` | 按下按键或组合键，包含修饰键与导航键 |
| `scroll` | 按页向上/下/左/右滚动某个元素 |
| `drag` | 在两个坐标之间拖拽 |
| `select_text` | 选中可编辑元素中的文本，或把光标放到其前后 |
| `perform_secondary_action` | 调用元素暴露的辅助功能动作——展开行、弹出菜单、取消等 |

按键与输入都投递给目标应用，因此**无法**触发全局系统快捷键。

## 实时预览

Agent 操作应用期间，Operon 会在会话旁边显示一个原生**实时预览**窗口，让你无需切换到该应用就能实时看到发生了什么。预览与截图相互独立——Agent 不需要为了维持预览而去截图。

## 审批

Computer Use 刻意比文件修改更谨慎。

- 没有已保存的允许或阻止规则时，Agent 在会话中首次操作某个应用前会先询问。
- 有真实后果的动作会在执行的那一刻要求确认，即使你在一开始已经批准了整体任务。
- 有一小类动作是**必须交还给你**的：Agent 会停下来请你自己完成。包括输入或修改密码、绕过浏览器安全警告、以及金融交易。
- 另一些动作永远不需要确认，因为它们不改变任何状态——读取、搜索、列举、总结。

**Settings > Computer > App access** 列出已保存的应用决定。用 **Always allow** 记住授权，**Block** 直接阻止，或移除规则以便下次重新询问。仅限会话的授权可以单独清除。密码管理器、终端、其他 Agent、macOS 安全提示和 Operon 自身始终禁止访问。

**Across all apps** 单独控制全屏捕获、读取或替换剪贴板。批准某个应用不代表同时批准这些更广的能力。

## 什么时候该用别的方案

Computer Use 是 Agent 手上最通用的工具，同时也是最慢、最脆弱的。只要存在专用路径，就优先用专用的：

- 你已登录的网页应用 → 用 [Chrome 扩展](chrome)，它驱动真实的浏览器标签页。
- 本地网页应用或一次性页面 → 用[内置浏览器](browser)。
- 任何有 CLI、API 或 [MCP 服务器](mcp-servers)的东西 → 直接用它们。
