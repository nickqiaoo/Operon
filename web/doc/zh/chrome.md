# Chrome

## 这是什么

Chrome 集成让 Agent 驱动**你自己的 Google Chrome**——你的标签页、你的登录态、你的 Cookie、你的历史记录。它面向那些只有在已登录会话中才成立的工作：你已经认证过的 SaaS 后台、SSO 背后的内部工具、你此刻正开着的某个页面。

## 配置

需要两块东西同时就位：Chrome 里的**扩展**，以及让 Chrome 能连回 Operon 的 **native host**。

1. 进入 **Settings > Chrome** 打开开关。这会为 Agent 安装 Chrome 技能，并注册 native host。
2. 在 **Connection** 区域，如果扩展还没装，从 Chrome 应用商店安装 Operon 扩展。
3. 装完后点 **Refresh** 重新检查。

## Agent 如何使用你的浏览器

因为这是**你的**浏览器，关于标签页的规则属于行为约定，而不是可有可无的整理：

- **Agent 在自己打开的标签页里工作。** 默认不会伸手去动你已有的标签页。
- **接管已有标签页是显式的。** 要操作你已经开着的页面，Agent 必须先"认领"该标签页，而且只在任务确实需要那个页面时才这么做。
- **Agent 打开的标签页是临时的。** 它们会在回合结束时关闭，除非 Agent 把该标签页标记为值得保留——它创建的文档、一个看板、一张填好的表单。
- **未完成的工作会交还给你。** 当任务需要你接手时——登录、支付、验证码——Agent 会保留那个标签页并交给你。
- **历史记录被视为敏感信息。** 只有任务明确需要时 Agent 才会读取。

## 确认

Agent 在这里做的任何事，都是**以你的身份**、从你已登录的会话发出的。以下动作 Agent 会先询问：

- 发送消息、发帖、提交表单；
- 购买、支付，或任何涉及资金流动的操作；
- 删除数据、修改权限、修改账户设置；
- 上传文件，或传输任何敏感信息。

如果你的请求本身已经授权了某个具体动作，就不会重复询问——"回复这封邮件说我会到"授权的是这条回复，而不是另一条。

## 关闭

关掉开关会从 Agent 那里移除 Chrome 技能，并注销 native host。扩展本身仍留在 Chrome 里，直到你自己删除它，但它已经没有可通信的对象了。

## 环境要求

macOS，并已安装 Google Chrome。扩展以 **Operon Browser Use** 的名字发布在 Chrome 应用商店；设置页会显示它的扩展 ID 并提供直达链接。
