# 助理

## 这是什么

Assistant 是一个跨工作区的个人助理。日常请求、后续跟进、项目协调都在一条持续的对话里进行，不必先选一个仓库。

从左侧边栏打开 **Assistant**；手机上使用 **Assistant** 标签。对话、活动和设置都属于当前连接的桌面端。

## 开始使用

1. 打开 **Settings > Assistant**，分别为 **Conversation**、**Work**、**Background checks** 选择 Agent 和模型。
2. 可以选择 **Operon**、**Claude Code**、**Codex**、**OpenCode**。CLI Agent 需要各自登录；Operon 需要配置 [AI Provider](providers)。CLI Agent 的工作会计入对应订阅的额度。
3. 回到 Assistant，介绍一下自己。你可以为它取名，也可以指定它如何称呼你。

Conversation 负责对话；Work 处理调研、文件、应用等通用任务。Background checks 运行心跳与定时任务，可以选择 **Same as Work**。修改 Conversation 会在下一条消息生效；继续已有任务时仍使用原来的 Agent。

## 任务与活动

用自然语言说出要做什么。助理可以把工作派出去，你继续聊天，完成后由它把结果带回对话。

**Activity** 面板显示正在运行、等待处理和已完成的工作。打开一条活动可以查看步骤与结果、追加指令或停止。通用任务可以使用已连接的插件，以及桌面端已启用的浏览器和 Mac 应用操作能力。

## 协调项目工作

你可以询问哪些工作区的对话还在运行、哪些事情在等你、项目看板上有哪些任务。助理可以：

- 在指定工作区启动编码 Agent，完成后汇报。Agent 和模型由你选择；没有指定或记住时，会先询问。
- 继续或停止由它启动的编码对话。每个对话都是普通的工作区聊天，你可以打开并接手。
- 需要隔离时创建带独立分支的工作区，也可以添加本地仓库或克隆项目。
- 按要求创建、更新看板任务，并添加评论。
- 使用你本机的 `gh` 登录读取 GitHub PR、审查与检查结果，或按要求创建 PR。

编码卡片显示工作区、Agent、模型和当前状态。提问和审批可以直接在卡片上回答，也可以点 **Open conversation** 进入对话处理。助理不会代你作答。

助理活动和看板任务是分开的：启动编码对话不会自动把它关联到看板任务或 PR。

## 记忆与资料

助理把精选事实、偏好和进行中的事情保存在自己的 **Memory** 中，细节放进每日笔记。开启新会话时会带上这些上下文，让可见的对话持续下去。

在 **Profile** 中查看或编辑 **Soul**（语气与性格）和 **Memory**；用名字旁的编辑按钮修改 **Identity**。也可以直接让它记住或忘掉某件事。这些笔记反映的是它的理解，发现错误或过时内容时可以修正。

助理的资料记忆与 Agent 对话共用的可检索[记忆库](memory)是分开的。记忆库可用时，它可以检索其中的旧上下文。

## 心跳与定时任务

**Schedule** 面板显示助理自己的任务，与侧边栏的 [Schedule](cronjob) 页面分开。

- **Heartbeat** — 每 30 分钟检查一次，依据检查清单和记忆里进行中的事情。让助理关注某件事，或用 **Edit checklist** 指定检查内容。没有内容可查时跳过；发现值得汇报的事情才开口。
- **定时任务** — 直接让它安排周期工作，例如每日简报。可以查看下次运行时间和最近结果、暂停或恢复、删除，或点 **Run now**。

心跳清单里的 **Already told** 记录用于避免反复汇报仍在持续的发现。无法执行的检查会记为未完成。需要登录的插件会显示在心跳卡片上，请到桌面端的 **Plugins** 连接。

在 **Settings > Assistant** 设置 **Quiet hours**（默认 23:00–08:00）。这些时段心跳只汇报紧急发现，其余等时段结束再说。后台工作需要桌面端保持运行。

## 审批与审核记录

通用任务需要许可时，会显示 **Allow once** 和 **Deny** 卡片。后台检查和定时任务会跳过仍需人工确认的步骤，并说明限制。

**Audit** 面板记录动作与审批决定。更多项目通知和待处理工作，见[通知](notifications)。
