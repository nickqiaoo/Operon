# 移动端

## 这是什么

Operon 的 iOS、Android 与网页端使用同一套远程应用。客户端通过托管的 Broker 访问桌面端运行的 Agent，同时使用端到端加密，让请求和响应内容只能由已配对设备与桌面端读取。

桌面端只需要主动连接 Broker，不需要公网 IP，也不需要开放入站端口。Broker 负责路由加密流量，但不持有内容加密密钥。

## 连接桌面端

1. 在桌面应用中打开 **Settings → Remote**。
2. 开启 Remote 并完成登录。
3. 使用远程客户端期间保持桌面应用运行。

Remote 卡片会显示连接状态，以及机器选择器中使用的名称。

## 配对设备

1. 在 iOS、Android 或网页端登录并选择机器。
2. 在桌面应用中打开 **Settings → Remote**，点击 **Pair device**。
3. 用远程设备扫描二维码。如果网页端和桌面端在同一台电脑上，点击桌面端的 **Copy pairing code**，再把内容粘贴到网页端。
4. 核对设备名称与指纹，然后在桌面端点击 **Approve**。

每个浏览器配置或原生安装只需配对一次。清除浏览器存储或重新安装应用后，需要重新配对。

## 端到端加密

远程 API 的请求与响应正文、AI 流、WebSocket 消息和附件内容都会在已配对客户端与桌面端之间加密。Broker 仍能看到完成路由所需的元数据。正式发布的客户端强制启用加密；仅开发环境保留本地调试开关，不向用户提供设置项。

已批准设备会显示在 **Settings → Remote → End-to-end encryption**。撤销设备后会立即失去访问权限，需要重新配对才能恢复。

## 故障排查

- **机器离线** — 打开桌面端 Operon，确认 Remote 显示 **Connected**。
- **网页端无法扫码** — 使用 **Copy pairing code**，然后粘贴到配对输入框。
- **一直等待批准** — 在配对码过期前回到桌面端，批准待确认设备。
- **再次要求配对** — 本地配对密钥可能已被清除或撤销，请生成新配对码重新配对。
