# 远程访问

## 这是什么

远程访问让你通过浏览器、iPhone 或 Android 设备驱动桌面端运行的 Agent。聊天、任务、文件、终端和 Git 审阅仍然使用你自己机器上的仓库与工具。

桌面端不会开放入站端口，只会保持一条到 Operon Broker 的出站连接。Broker 把远程请求路由回选中的机器；请求和响应内容在每个已批准客户端与桌面端之间端到端加密。

## 连接

1. 在桌面应用中打开 **Settings → Remote**。
2. 开启 Remote 并完成登录。
3. 打开网页端或移动端，登录并选择机器。
4. 按客户端提示完成一次安全配对。

无法扫描二维码时如何粘贴配对码，请参阅[移动端](mobile)。

## 远程可用功能

聊天、任务、频道、文件、终端和 Git 审阅都可通过 Broker 使用，包括 AI 流式响应和停止正在运行的回合。

部分直接控制桌面硬件的设置不会显示在远程构建中，包括内置 Browser、Computer Use、Chrome 控制、桌面日志和 Remote 设置页本身。

## 断开

在桌面端关闭 Remote。这台机器会从 Broker 注销，远程客户端将无法继续访问。本地会话、任务和仓库不会改变。
