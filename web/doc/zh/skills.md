# 技能

## 这是什么

技能是一包可以随时装上的指令，让 Agent 具备处理某类任务的专门知识。可以把它当成一份专家写的操作手册——当 Agent 遇到与某个技能对得上的活儿（比如审查网页设计、整理提交信息），它就会去读那份手册，照上面的具体做法办。

## 工作原理

一个技能就是一个 Markdown 文件（`SKILL.md`），里面写着名字、简介和详细做法。每开一个新对话，Operon 会把所有技能的名字和简介交给 Agent；当 Agent 判断你的要求正好落在某个技能的范围里，才会去读它的完整内容。

技能统一放在 `~/.agents/skills/`，由底层的 CLI 工具管理。你可以从 GitHub 仓库装现成的，也可以自己写。

## 怎么用

### 浏览与安装

1. 从侧边栏进入 **Skills** 页面。
2. **Installed** 里是当前已经装好的技能。
3. **Browse** 可以从 GitHub 仓库里搜（默认是 `vercel-labs/agent-skills`）。
4. 点 **Install** 装上，之后每个新对话都能用。

### 卸载

在已安装的技能上点删除按钮即可。

### Agent 怎么用技能

不需要你手动启用。Agent 会自己判断哪个技能和当前的要求有关，再决定读不读。举个例子：装了 "web-design" 技能之后，你让 Agent 看看你的界面，它就会照着那份技能给出更专业的意见。

### 自己写一个

新建一个带 YAML frontmatter 的 `SKILL.md`：

```markdown
---
name: my-skill
description: "一句话说明这个技能是干什么的"
---

给 Agent 看的详细说明写在这里……
```

把它放到 `~/.agents/skills/my-skill/SKILL.md`，下次开新对话时就会被认出来。
