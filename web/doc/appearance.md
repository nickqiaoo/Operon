# Appearance

**Settings > Appearance** covers how Operon looks and what language it speaks.

## Language

The interface is available in **English** and **简体中文**. Switching takes effect immediately — no restart.

This setting changes Operon's own UI only. It does not instruct agents what language to reply in; tell them that in your message, or in an agent's instructions.

## Theme

**Light**, **Dark**, or **System** — System follows macOS and switches with it.

## Color presets

Light and dark each get their own preset, so you can pair, say, GitHub Light with Tokyo Night and have each mode look right on its own terms.

| Dark presets | Light presets |
| --- | --- |
| Default, One Dark, Nord, Dracula, Tokyo Night, Catppuccin, Gruvbox, Solarized, Rose Pine | Default, One Light, Nord Light, GitHub, Tokyo Night Day, Dracula Light, Catppuccin Latte, Gruvbox Light, Solarized, Rose Pine Dawn |

## Terminal theme

The embedded [terminal](terminal) has its own light and dark presets, set separately from the UI theme. Terminal color schemes carry conventions of their own — and the palette that reads well in a shell is rarely the one you want behind a chat — so the two are deliberately not linked.
