07 — Elevation & Shadows
Exactly five semantic elevations — Tailwind's default shadow-sm/md/lg/xl scale is disabled at build level. Light mode uses short, slate-tinted shadows that only draw the edge; each token carries its own deeper dark-mode value, so components never write dark:shadow-[...]. Never hand-write a new shadow literal — tune the --elevation-* tokens instead.
Card — shadow-card
--elevation-card · resting cards, chips, form controls
Input — shadow-input
--elevation-input · chat composer, diff cards
Float — shadow-float
--elevation-float · menus, popovers, toasts, drag
Modal — shadow-modal
--elevation-modal · dialogs
Drawer — shadow-drawer
--elevation-drawer · right slide-in panels (directional)

11 — Design Principles
Brand vs Tint
Brand (--color-brand, purple) is reserved exclusively for the logo SVG. Tint (--color-tint, neutral gray) is used for all UI interaction: active indicators, focus rings, selected states, and hover feedback. To re-theme the UI, change only the 4 tint variables.
Borders
One color, three steps. All borders use --color-border with a fixed opacity ladder: /40 quiet separators · /50 default structure · /60 card & popover edges. Dark mode drops to dark:/35. Full opacity only for hover/focus emphasis. Never black borders, never freeform steps.
Surfaces
Hierarchy comes from surface steps, not shadow weight: canvas #f7f8fb → muted #edf0f5 → popover white. Sidebar sits on --color-sidebar: #f2f3f6. Inside dialogs, form fields recess via --color-dialog-field (2% foreground mix — a whisper, not a slab).
Motion
App entrance: 520ms ease-out with translateY(10px).
Panel stagger: 560ms ease-out, 60ms delay increments.
Terminal toggle: 200ms ease-in-out.
Hover transitions: 150ms default.
